## Types of the badges
Badgers come in two versions (1 and 2) with two variants (white and color). Four in total.
### Type1Color
A color variant with
- Visual
- Quality
- Resolution
- Audio
- Channels
- Streaming platforms
- and IMAX?
### Type1White
The same as [Type1Color](https://github.com/k-flop/badgers/#type1color), but white... obviously
